Evidence

Prove which model actually answered

A model will tell you whatever its client's system prompt says it is. That is useful conversation, not identity evidence.

17 August 2026·By 48Nauts·6 minute read

Ask a language model who it is and the answer usually reflects the harness around it. A client can label the assistant Claude, GPT, Gemini or anything else. The model then continues that fiction politely and confidently because following the prompt is the job.

The request creates a second source of confusion. It contains the model the caller wanted, but routing layers can alias, override or substitute that value before a provider serves the call. Keeping only the request gives you a record of intent, not a record of delivery.

Requested is what the caller asked for. Served is what the provider says generated the response. A trustworthy audit log needs both.

Read the response, not the request

NautGate parses the served model from the provider's own response and writes it beside the requested model. When the two differ, the routing-flow view highlights the hop where the substitution happened.

That small distinction supports everything downstream. Cost attribution uses the model that actually produced the tokens. Drift and quality comparisons group calls by the model that actually answered. Compliance evidence can show the provider and data path rather than infer them from a client label.

Make it cross-checkable

Evidence should not require faith in NautGate either. Token counts and the served model can be compared with the provider's billing dashboard. The same call should line up to the token. If it does not, the discrepancy is visible instead of being normalized away.

The routing record

For each call, the record keeps the client, credential lane, routing decision, upstream provider, requested model, served model, token counts, timings and cost together. Policy-gated prompt and response capture can add the content when that is appropriate, with PII and secret classification before storage.

Plenty of gateways route. The difference is remembering enough to prove what the route did.
