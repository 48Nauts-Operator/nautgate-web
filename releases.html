v0.2.0

LATEST17 August 2026

The first release prepared for anonymous public installation on macOS and Linux: a native CLI, Homebrew formula, public images and the go-live fixes that make the evidence trustworthy.

Added

  • nautgate serve and nautgate status, plus brew install 48nauts-operator/tap/nautgate.
  • Public multi-architecture images for NautGate, NautRouter and NautProxy.
  • 442 selectable models, local-model routing, compliance traces, universal capture and tool-call normalization.
  • Provider credentials managed in the dashboard and encrypted at rest.

Fixed and verified

  • Provider errors, streaming usage and costs, pricing, backups, retention, CORS and long-request timeouts.
  • Dashboard admin tokens are no longer exposed to remote browsers.
  • 476 tests, the final Docker smoke, anonymous image pulls, a clean Ubuntu 24.04 install and Homebrew's strict online audit all passed.

v0.1.0

23 July 2026

The first public release: one endpoint for coding agents and apps, with an attested audit record for the model that actually served every call.

Highlights

  • OpenAI Chat and Anthropic Messages inbound formats with separate OAuth subscription and metered-key lanes.
  • Per-key model override, LM Studio routing and silent-substitution detection.
  • Policy-gated prompt and response capture, routing-flow evidence, quality scoring, drift detection and cost analytics.
  • A self-contained Docker image, provider-key management encrypted at rest, working backups and first-run onboarding.
