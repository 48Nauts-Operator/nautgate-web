v0.5.0

LATEST24 August 2026

Max Guard protects Claude Max capacity from runaway agent sessions, while the new Observatory turns routing, cache, quality, privacy, account and team evidence into a focused operational view.

Max Guard

  • Tracks fresh input, cache reads and writes, output, requests, project-hour pressure, and rolling five-hour and weekly capacity windows—even when subscription traffic has zero API cost.
  • Attributes native xNaut launches by application, project, run and Claude session without requiring Claude Code's problematic --bare launch behavior.
  • Supports explicit observe, warn and pause policies. Paused requests receive a structured non-retryable response and never fall through to metered Anthropic credits.
  • Persists capacity reservations and reconciled usage, with auditable pause, resume and temporary authorization controls.

Observatory and evidence

  • Summary combines observed work, token-consuming projects, live Max Guard risk, Lighthouse privacy, quality, drift, traffic and paginated sessions linked to Audit Log.
  • Team connects active and inactive ng_ identities to fresh input versus cache reads, compliance findings, sessions and sortable Agent Streams.
  • Accounts compares subscription value with API spend per provider and period, including provider status, cache use and live OpenRouter credit.
  • Compliance explanations show the evidence chain, measured impact and attribution limits, export JSON evidence, and label missing metadata as unavailable instead of guessing.

Fixed and verified

  • Anthropic-compatible cache reads and writes are recorded independently, and stable repeated prefixes without cache reuse can trigger Max Guard evidence.
  • Provider-scoped charts, confidentiality state, Lighthouse score, quality evidence, session pagination and active/inactive team windows now use their actual backing data.
  • 593 core tests, lint and format checks, the NautRouter and documentation production builds, local and hosted go-live smokes, and all multi-architecture image publications passed.

v0.4.0

21 August 2026

A verifiable audit trail and a fail-closed local inference boundary: operators can prove how a call was routed, keep detected PII and secrets off cloud transports, and use Claude Max from ordinary NautGate clients.

Added

  • Verified Audit Trail v1 with canonical decision receipts, deterministic Merkle checkpoints, optional Securosys TSB signing, portable evidence bundles and offline verification.
  • Confidential routing that combines NautGate and Bowden detection, lets the operator choose an LM Studio model, and takes precedence over explicit, per-key, plugin and OAuth routes.
  • A server-side Claude Max transport for ordinary ng_ clients, avoiding accidental fallback to a metered Anthropic API key.
  • Conversation-scoped sessions, direct session-to-Audit Log navigation, visible local-route match flags, collapsible navigation and paginated evidence receipts.

Fixed and verified

  • Static Claude Code tool documentation no longer produces false PII or secret matches; real tool arguments and results remain classified through message history.
  • Anthropic OAuth can no longer bypass the confidential boundary, and an unhealthy local route can probe its own recovery without ever falling back to cloud.
  • 571 core tests, 21 attestation tests, lint and format checks, Homebrew resource verification, Compose rendering, local and hosted go-live Docker smokes, and all three multi-architecture image publications passed.

Proof boundary: Verified Audit Trail is disabled until an operator configures signing. A verified bundle proves inclusion in an unchanged signed checkpoint; it does not prove that every real-world event was observed or make a system compliant by itself.

v0.3.0

20 August 2026

Subscription-aware routing becomes a real client transport: ordinary NautGate keys can use the operator's ChatGPT plan, while every response carries enough routing evidence for clients to show what was requested, selected and actually observed.

Added

  • ChatGPT subscription routing for explicit supported GPT models from ordinary ng_-authenticated clients, including streaming-compatible responses and notional savings.
  • Routing receipt headers on successful and failed calls: requested, selected and observed model, substitution status, decision ID and upstream status.
  • An optional Securosys TSB extension that binds hardware-signed attestation receipts to NautGate decisions.

Fixed and verified

  • Tool-bearing requests no longer enter the subscription transport that cannot execute function calls.
  • Automatic-routing fallbacks now use real OpenRouter catalogue IDs, and Anthropic 529 retries keep exponential backoff even when Retry-After is zero.
  • 492 core tests, 13 attestation tests, the go-live Docker smoke, strict online Homebrew audit and anonymous pulls for all three multi-architecture images passed.
